# 🚀 Smart City Service App

🛠️ A web-based application that allows citizens to raise complaints using OTP-based authentication.

✨ Features:
- 📱 Phone number login with OTP
- 🏙️ Citizen, Councillor & Collector dashboards
- 📍 Location-based issue reporting
- 📸 Camera integration
- 🗺️ Map-based visualization

🧪 Tech Stack:
- Python
- Streamlit
- Firebase
